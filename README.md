🧠 PyTorch Self-Attention & Multi-Head Attention
This repository provides a step-by-step educational implementation of Self-Attention and Multi-Head Attention mechanisms using PyTorch. 
It breaks down the core mathematics behind Transformer models by explicitly calculating Queries (Q), Keys (K), Values (V), and scaled dot-product attention scores for toy text sequences (e.g., "Man eat cheese").

Key Features:
Step-by-Step Math: Explicit, line-by-line calculations of raw attention scores, scaled scores, and Softmax distributions.
Multi-Head Attention: Demonstrates how to linearly project inputs, split them into multiple attention heads, compute attention independently, and concatenate the results.
Visualizations: Includes side-by-side heatmaps using matplotlib and seaborn to intuitively visualize how attention weights are distributed across source and target tokens.
Perfect for beginners looking to understand the inner workings of Transformer attention mechanisms from scratch!
